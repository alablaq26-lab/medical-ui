# Medical UI: Doctor Visit Interface

A clean, responsive interface for doctors to review a patient and record a visit. Built with **Next.js**, **TypeScript**, and **shadcn/ui**. This is a front-end prototype that runs on sample patient data.

## Features
- Patient header with key details
- **Active problems** and **allergies** at a glance
- Forms to add a new **symptom**, **diagnosis**, **lab result**, and **prescription** during a visit
- Component library based on Radix UI and Tailwind CSS
- Light/dark theme support and mobile-friendly layout

## Tech Stack
Next.js · React · TypeScript · Tailwind CSS · shadcn/ui (Radix UI) · React Hook Form


## Getting Started
```bash
git clone https://github.com/alablaq26-lab/medical-ui.git
cd medical-ui
npm install
npm run dev
```
Open http://localhost:3000

## Main Component
`components/patient-visit-view.tsx` contains the visit screen. It is rendered from `app/page.tsx`.

## Part of HealthKey
This UI is a prototype for the doctor side of the [HealthKey](https://github.com/alablaq26-lab/HealthKey_1) system.
